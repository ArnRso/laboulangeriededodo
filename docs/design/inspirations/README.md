# Inspirations

Captures et références visuelles. Le tableau dit d'où elles viennent et ce
qu'on en retient.

## Pinterest — ambiance générale (22/08/2026)

Ce qu'on a pris de l'ensemble : cartes très arrondies, palette pastel
saturée (lilas, rose, pêche, jaune), formes douces en fond, esprit jeu /
cadeau plutôt qu'outil. On a écarté l'iconographie 3D et les onglets de
navigation en bas.

| Fichier | Source | Contenu | Ce qu'on y prend |
|---|---|---|---|
| `pinterest-morflax-game-store.jpeg` | Dribbble, Morflax | Store de jeux mobile : carte « Today » Clash Royale, catégories en tuiles dégradées (Action, Board, Card, Family), blobs pastel en fond | Tuiles colorées à dégradé par catégorie → une couleur par app dans le fil |
| `pinterest-ofspace-quiz.jpeg` | Ofspace Digital Agency | Quiz éducatif : cartes de quiz illustrées, chips de réponse, écran « +250 Point » avec étoile filante | L'écran de récompense → le toast d'aura à l'ouverture |
| `pinterest-birthdaily-reminder.jpeg` | « Search Page UI Design » | Birthdaily : memojis dans des tuiles colorées, ballons, calendrier des anniversaires, fiche personne avec « Shared Moments » | Avatars emoji dans des pastilles colorées, fond rose-pêche |
| `pinterest-crow-game-type.jpeg` | 乌鸦Crow | Jeu mobile : personnage 3D sur fond rose → violet, cartes « Game type » en verre dépoli | Dégradé rose → lilas, cartes translucides (base du style « écran verrouillé ») |
| `pinterest-timeboard.jpeg` | Dribbble, Imran Hossen | TimeBoard : tableau de tâches, cartes colorées avec gros horaires, post-its | Horaires en gros caractères → l'horloge de l'écran verrouillé |
